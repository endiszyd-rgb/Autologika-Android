AUTOLOGIKA ANDROID 0.31.0 — START NA JUTRO

1. Rozpakuj paczkę do osobnego katalogu. Porównaj z lokalnymi zmianami z PC.
2. Użyj Node 22 LTS lub Node 24.
3. npm ci
4. npm run check:source
5. npm test
6. npm run check:release-version -- 0.31.0
7. Uruchom development build Androida przez npx expo start albo zbuduj APK.
8. Lokalny APK: cd android, następnie ./gradlew assembleRelease.
   W PowerShell: .\gradlew.bat assembleRelease.
9. Użyj dotychczasowego klucza podpisującego, aby zainstalować aktualizację.
10. Wykonaj testy na telefonie/tablecie opisane w ZMIANY_0.31.0.md.

Szczegółowa lista zmian, wymagania i ograniczenia: ZMIANY_0.31.0.md.

Wersja PC pozostaje bez zmian.
