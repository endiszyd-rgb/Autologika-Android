AUTOLOGIKA 0.20 / ANDROID 0.5 — JUTRO START HERE

1. Na PC rozpakuj Autologika_OS_MVP_0.20.zip do nowego katalogu.
2. Użyj Node 22 LTS. W PowerShell korzystaj z npm.cmd.
3. npm.cmd install
4. npm.cmd run rebuild
5. npm.cmd run dev
6. W Supabase uruchom/zweryfikuj cloud_schema_supabase.sql.
7. Zaloguj Desktop i Android na to samo konto.
8. Test rekordu: utwórz testowe zlecenie na PC -> synchronizuj -> sprawdź tablet.
9. Test zdjęcia: tablet / PRZYJĘCIE -> Cloud -> PC.
10. Test kategorii: dodaj zdjęcia DIAGNOZA i NAPRAWA; sprawdź ich podział na obu urządzeniach.
11. Test usunięcia: usuń jedno testowe zdjęcie na tablecie -> synchronizuj -> sprawdź, czy znika z PC. Potem odwrotnie.
12. Test PDF offline na Androidzie: Dokumenty -> Otwórz PDF bez Wi-Fi.
13. Test backupu desktop: Ustawienia -> Dane i backup; sprawdź automatyczną kopię.
14. Dopiero po tych testach przechodzimy do rzeczywistych danych klientów.

Nie kopiuj service_role do żadnej aplikacji klienckiej.
